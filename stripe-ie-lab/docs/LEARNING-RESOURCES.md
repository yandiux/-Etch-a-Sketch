# Learning resources (IE path, not full CS degree)

**On the bus (no laptop):** [COMMUTE-LEARNING.md](./COMMUTE-LEARNING.md)

## Priority order

1. **javascript.info** — async chapters (free, precise)
2. **Scrimba Pro** — async + fetch only, 90 min/week max
3. **This lab** — drills then projects
4. **Stripe docs** — when building, not before Phase 0 async

## javascript.info (read in order)

- [An introduction](https://javascript.info/intro) — skim if needed
- [Code quality](https://javascript.info/code-quality) — optional
- [Objects](https://javascript.info/object) — refresh
- [Destructuring assignment](https://javascript.info/destructuring-assignment)
- **Async block (required):**
  - [Callbacks](https://javascript.info/callbacks)
  - [Promises](https://javascript.info/promise-basics)
  - [Promises chaining](https://javascript.info/promise-chaining)
  - [Error handling with promises](https://javascript.info/promise-error-handling)
  - [async/await](https://javascript.info/async-await)

## Scrimba Pro — how to use without tutorial hell

- Pick **one** path section: asynchronous JavaScript
- Every 3–5 minutes: pause, close screencast, retype in VS Code
- End of session: one sentence “what I learned” in [weekly-bridge-log-template.md](./deal-bridge/weekly-bridge-log-template.md)
